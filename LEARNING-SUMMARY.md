Learning Summary

During this training week, I learned the following:

Java Basics
- Understanding the difference between JDK and JVM.
- Compiling and running Java programs.
- Using variables, conditions, loops, and methods.
- Comparing strings correctly.

2. Object-Oriented Programming
- Creating classes and objects.
- Using constructors and getters.
- Working with enums and ArrayList.

3. Exception Handling and Validation
- Handling invalid user input.
- Validating empty fields and duplicate device IDs.
- Handling unsupported device types.

 4. Maven
- Understanding the Maven project structure.
- Working with the `pom.xml` file.
- Running Maven commands such as `mvn clean compile`, `mvn test`, and `mvn package`.

5. Git and GitHub
- Creating repositories and commits.
- Working with branches.
- Creating and merging Pull Requests.
- Identifying and resolving merge conflicts.
- Documenting the conflict resolution process.
6. Practical Experience
I applied what I learned by developing a Java console application called Device Registry, which allows users to add, list, and search for devices.

This project helped me practice Java programming, input validation, Maven, and Git workflows.
